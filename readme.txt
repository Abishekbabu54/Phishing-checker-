# Phishing URL Scanner

A desktop application that analyzes URLs for potential phishing threats and security risks. This tool helps users identify potentially dangerous websites by examining various security features and risk factors.

## Features

- URL Security Analysis
- Domain Age Verification
- Suspicious Term Detection
- TLD (Top Level Domain) Validation
- Risk Score Calculation
- Detailed Security Recommendations
- User-Friendly Interface

## Usage

1. Launch the application by double-clicking `PhishingScanner.exe`
2. Enter a URL in the input field (with or without http/https)
3. Click "Analyze" to start the scan
4. Review the results:
   - Risk Level
   - Risk Score
   - Detected Risks
   - Security Recommendations
   - Domain Information

## Understanding Results

### Risk Levels

- **Low** (0-29): URL appears to be safe
- **Medium** (30-59): Some concerning factors detected
- **High** (60-79): Multiple risk factors present
- **Critical** (80-100): Significant security risks identified

### Security Checks

The scanner analyzes:
- HTTPS encryption
- Domain age
- Suspicious keywords
- TLD legitimacy
- URL structure
- Domain registration information

## System Requirements

- Windows 7/8/10/11
- No additional software required
- Minimum 100MB free disk space
- Internet connection for URL analysis

## Privacy & Security

- All analysis is performed locally
- No data is sent to external servers
- No personal information is collected
- Internet access is only used for URL verification

## Troubleshooting

Common issues and solutions:

1. **Application won't start**
   - Ensure you have administrator privileges
   - Check antivirus isn't blocking the application
   - Verify the executable isn't corrupted

2. **URL Analysis Failed**
   - Check your internet connection
   - Verify the URL format is correct
   - Try adding 'http://' or 'https://' prefix

3. **Slow Analysis**
   - First launch may take longer to initialize
   - Complex URLs may require more analysis time
   - Check your internet connection speed

## Disclaimer

This tool provides an analysis based on common phishing indicators but should not be the sole factor in determining a website's safety. Always exercise caution when visiting unfamiliar websites and protect your personal information.
